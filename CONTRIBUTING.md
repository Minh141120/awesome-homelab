# Contributing

Thanks for helping. This list is organized like a home-ops Git repo: each layer has **tools**, **In the wild** links to real configs, and **Read** links to guides.

## What can you add?

- **A tool:** add `- [Name](url) - Description.` to its layer. Order is by popularity in home-ops repos, not alphabetical, so put it where it fits and explain why in the PR.
- **An In the wild link:** add `- **owner** — [path/](url)` under the layer's In the wild list. Link to the folder or file in a public repo that shows the pattern best.
- **A Read or Watch link:** add a free guide, post, or video to the layer it teaches.
- **An app:** add a row to the 10 Apps table with its homepage, a few words on what it does, its [kubesearch.dev](https://kubesearch.dev) page, and one real deployment if you know a good one.
- **A real repo:** add a row to the Real Repos table, with its stack and the best place to start reading.

## Rules

- Free resources only: open-source software, and free articles, videos, and courses. No paid products or paywalled content.
- Projects must be maintained, meaning a commit in the last 12 months. Archived projects are removed.
- Write short, neutral descriptions that start with a capital letter and end with a period. No marketing language.
- Link to the canonical URL. Check for redirects and renamed repos.
- Disclose any affiliation with what you add.
- Use one pull request per addition.

Passing CI isn't enough. Every addition is reviewed by a human.
